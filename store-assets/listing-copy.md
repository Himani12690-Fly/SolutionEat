## Data safety form — quick reference

Based on what the app actually collects (see [privacy.html](../privacy.html) for the full policy):

| Data type | Collected? | Shared? | Purpose |
|---|---|---|---|
| Name | Yes | Yes (with the kitchen you order from) | Account management, order fulfillment |
| Email address | Yes (via Google Sign-In) | No | Account management |
| Phone number | Yes | Yes (with the kitchen you order from) | Account management, order fulfillment, OTP verification |
| Address | Yes (delivery address) | Yes (with the kitchen you order from) | Order delivery |
| Approximate location | Yes (with permission) | No | App functionality (show nearby kitchens) |
| Order/purchase history | Yes | Yes (with the kitchen you order from) | App functionality, account management |
| Device/other IDs | Yes (FCM push token) | No | App functionality (push notifications) |

- **Data encrypted in transit**: Yes (HTTPS)
- **Users can request data deletion**: Yes — via email to himanibabaria@gmail.com
- **Financial info (card/UPI numbers)**: Not collected — payment is Cash on Delivery or handled outside the app (no card/UPI credentials stored)
